# Character galleries

Four independent character folders are prepared:

- `male-01/`
- `male-02/`
- `female-01/`
- `female-02/`

Each has four blank PNG image slots and its own gallery page. Replace `render-01.png` through `render-04.png` with your real PNG renders under the same names, and commit to `main`. Every character gets the same 3D animation. No character artwork has been invented. Use `data/projects.json` to rename characters and set render captions when you have chosen their final names.
