# Environment projects

Each environment keeps its own gallery and image slots:

- `forest/` — Forest Light Study
- `rain-night/` — Rain & Night Study
- `alcatraz/` — The Alcatraz Escape

Replace a file inside its own project folder using exactly the same filename and extension, then commit to `main`. See each folder's README for its gallery link. Do not combine different environments into the same project's images.
