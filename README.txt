OWNER STUDIO & MULTI-IMAGE GALLERIES
Open admin.html for the email/password project editor.
One-time Supabase setup is required for real login, uploads and publishing:
see CMS-SETUP.md and supabase/setup.sql. Configure public connection values
in cms-config.js; never add service-role keys or passwords to the repository.
Public gallery data falls back to data/projects.json when no CMS is connected.

REPLACE YOUR RENDERS DIRECTLY IN GITHUB
All project files are organized under assets/projects/. See its README.md.
Most galleries have four slots. Mocha Wood has five uploaded JPEG/PNG renders.
Male Character 01 has five uploaded JPEGs;
Female Character 01 has six blank JPEG slots for your renders.
Replace a slot with a real image of the exact same filename/extension and
commit to main. This updates the animated card and gallery without a CMS.
Characters have separate male-01, male-02 and female-01 folders.

GALLERY VIEWER
Project cards now open centered on the same page with animated transitions.
