One-time CMS connection needed

Your login and media storage need a free Supabase project. The website stays online while you connect it.

  1. Create a free project at Supabase ↗.
  2. Run supabase/setup.sql in its SQL Editor.
  3. Create your owner user in Authentication → Users, then add that user to portfolio_admins as explained in CMS-SETUP.md.
  4. Set your project URL and public publishable key in cms-config.js. Never add a secret or service-role key.
